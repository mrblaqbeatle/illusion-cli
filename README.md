# Illusion CLI

Illusion is a lightweight, terminal-first AI assistant built for developers who want **hands-on (or no-hands) programming** without expensive hardware, subscriptions, or complicated setups.

This tool exists because I was once in the same position: limited compute, limited money, but a strong desire to build.

Illusion is for people who love the terminal — whether that terminal lives on a laptop, a shared PC, or a phone running Termux.

---

## Why Illusion Exists

Not everyone has:
- A powerful laptop
- Paid AI subscriptions
- Access to modern IDEs

But many people *do* have:
- A terminal
- Curiosity
- The will to learn and build

Illusion is designed to meet you **where you are**, not where a marketing page assumes you are.

---

## Features (What It Does)

Illusion helps you:
- Generate project structures
- Create code and boilerplate
- Build websites and apps
- Interact with AI directly from the terminal
- Work in a keyboard-first (or script-first) way

It is:
- Free
- Cross-platform
- Local-first (no servers run by us)
- Early-stage and evolving

This is not a “big-guns” AI CLI. Think of it as a **reliable Corolla**, not a Formula 1 car — and that’s intentional.

---

## Installation

```bash
pip install illusion-cli
```

After installation:

```bash
illusion
```

If the command runs, you’re good.

---

## Configuration

Illusion requires an API key to function.

Run:

```bash
illusion config
```

Follow the prompts to set it up.

---

## Termux & Mobile Users (Important)

Illusion **can work in Termux**, but Python dependencies can sometimes be painful in a plain Termux environment.

### Recommended (but not required):

Use `proot-distro` to install a Linux distribution (Ubuntu, Debian, etc.) inside Termux, then install Illusion there.

Why?

* Fewer dependency issues
* Easier Python package installs
* Less frustration

If you already have everything working in plain Termux — that’s perfectly fine too.
